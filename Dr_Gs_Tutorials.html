Dr. Gutow's chemistry related interactive tutorials

This is a mirror of the tutorials available at Dr. Gutow's website.
  • Tutorial on drawing Lewis structures. Includes some practice examples with answers at each intermediate step.
  • Tutorial on estimating molecular shapes. This describes how to apply the VSEPR model to estimate the shapes of molecules for which you have determined the Lewis structures. This tutorial includes 3-D visualizations of some molecules of each shape that you can manipulate.
  • Visualizations of atomic and molecular orbitals (where the electrons are):
    • Atomic orbital viewer. 3-D visualizations of atomic orbitals on some many electron atoms that you can manipulate.
    • Tutorial and visualizations of hybrid atomic orbitals which are used to model bonding in terms of electron overlap.
    • Visualization of pi-bonding (double bonding) in ethylene utilizing the hybrid orbitals.
